# Counterparty-Credit-Risk-MC
This project focuses on Counterparty Credit Risk (CCR) estimation for an interest rate swap portfolio using a Monte Carlo simulation based on the Hull-White extended Vasicek model. It simulates discount factor curves across 250,000 scenarios to calculate Mark-to-Market (MtM) values, Expected Positive Exposure (EPE), and 95% Potential Future Exposure (PFE) profiles over time. The repository systematically evaluates the risk-mitigating impacts of mandatory break clauses, netting agreements, and Credit Support Annex (CSA) margin calls, and includes estimations for Credit Valuation Adjustments (CVA).

### Project context: 
Assignment for the Financial Engineering course @ Politecnico di Milano
